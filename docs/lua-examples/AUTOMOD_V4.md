## English summary

Update the existing script (same script ID and approvals). The 48 KiB source quota is required; legacy settings and escalation shards remain valid. Engine A uses up to five references, exact non-consecutive matches and a +1 rapid score bonus; B normalizes Unicode spaces and dictionary-backed trailing repeated letters, recognizes demographic/geographic variants, and groups explicit contact and location requests conservatively. ## Memory verification / verifica memoria

The native host test measures the real allocator peak and live heap after a full garbage collection at each stage (configuration, JOIN churn, five A groups, nickname/account/host changes, A and B detections, expiry). Full GC is test-only JNI, not a script API or an Android build feature. The 2 MiB VM limit is unchanged; 75% is a design target, not a measured result until the CI reports it. Historical on-disk storage and report formats remain unchanged.

### Compact retained state / stato compatto

Each A/B reference is a packed in-memory record (full normalized text, count, time, previous/trigger source and B start time or A credit). Source-session UUID prefixes are shared through a bounded 32-entry dictionary with an exact raw fallback; the original source ID is restored for every report. Graph groups and channel watches are positional arrays; nicknames are a flat list of nickname/time/domain triples shared with the active-session index. The legacy v4.sNN format is unchanged; v4.gN uses a backwards-readable, balanced grouped format. The native VM starts with incremental GC pause 110% and step multiplier 300%, instead of Lua's 250% pause; the hard 2 MiB, 200,000 instruction and global memory limits remain in force. These settings apply to all VMs; native regressions and paced latency tests must pass before merge.

### Balanced persistent identity archive / archivio identità bilanciato

The six existing v4.g0–v4.g5 values still have an 8192-byte limit each; the 32-key, 128 KiB storage quota, 12 actions per callback and 2 MiB Lua heap remain unchanged. The new !3 format groups full exact signatures by network/root/time/epoch, sharing the root and timestamp. Legacy rows can be read and are migrated on the next live decision. A deterministic size-balanced allocation across the existing six values replaces fixed per-key partitioning. Old-epoch or expired links are removed, and the complete new layout is checked before any escalation write or sanction is emitted. The source quota alone increases to 48 KiB to accommodate the codec; no additional runtime privileges or heap allowance. If the complete archive cannot fit, moderation is suspended for that decision and the existing history is not overwritten. Native callback errors discard all queued actions.
