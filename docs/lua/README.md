# TIARCA Lua scripting — Developer documentation

TIARCA's embedded Lua scripting API is an **experimental development feature** on `main`; it is **not available in the published v0.9.10 APK**. This documentation describes the app's restricted API, not unrestricted Lua or IRC protocol access.
